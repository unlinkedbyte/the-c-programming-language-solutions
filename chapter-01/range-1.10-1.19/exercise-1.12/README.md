### Behind the code
To be honest, this exercise took me much longer than expected. The problem with my first attempt was the extra spaces, which were also being printed as a new line. Being able to understand the flow was hard to visualize. This is where the importance of saving states came in. If the loop starts with a space, it simply restarts (remember we are outside the word) until a character arrives and it enters the else block. When it enters the else block, we reset the state with one purpose: to tell the first and second if whether we are coming from a word or not. If we are coming from a word, it prints a line break, and if we are not, it simply does nothing and the loop restarts.
